# Website Monitor UI 改版设计说明（v1 待定版）

> 配套原型：`design/ui-prototype.html`（单文件、离线可开、可切换强调色与密度）
> 范围：master 管理端全部页面；不含 monitor 客户端（无界面）。

---

## 1. 设计目标

| 目标 | 具体做法 |
|---|---|
| 工具感 | 信息密度优先，13px 基准字号，表格行高 44px，数字与 URL 全部等宽 |
| 简约 | 中性灰 + 单一强调色；用 1px 描边与背景差分层，不用投影和大色块 |
| 少打断 | 站点详情、报警详情改为右侧抽屉；上下文留在页面上 |
| 可扫读 | 状态用圆点 + 短文本；操作收敛为「主操作 + ···」；批量操作浮出 |
| 一致性 | 一套页头、工具栏、表格、表单、空状态、Toast 组件 |

当前版本的主要问题：深色顶栏 + 浅灰侧栏割裂；卡片悬浮阴影过重；每行 8 个图标按钮没有主次；表格与弹窗承担了过多信息；导航把「面板」和「站点列表」混在一起。

## 2. 视觉系统

### 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--bg-app` | `#F6F6F7` | 页面底色 |
| `--bg-surface` | `#FFFFFF` | 面板、表格、抽屉 |
| `--bg-subtle` | `#FAFAFA` | 悬浮、次级区块、代码底 |
| `--bg-active` | `#EFEFF1` | 导航选中、批量条 |
| `--border` | `#E7E7EA` | 1px 分隔线 |
| `--border-strong` | `#D6D6DB` | 输入框、次按钮边框 |
| `--text` | `#18181B` | 主文本 |
| `--text-2` | `#5B5B66` | 次文本、表头 |
| `--text-3` | `#93939E` | 弱文本、时间、占位符 |
| `--accent` | `#4F46E5` | 主按钮、选中态、图表 |
| `--ok / warn / danger` | `#15803D / #B45309 / #C02626` | 状态语义 |

强调色提供三套可切换：
- **靛蓝 `#4F46E5`**（默认，产品感强）
- **青绿 `#0F766E`**（运维/监控感，和"在线"语义更贴）
- **石墨 `#27272A`**（近乎单色，最克制）

规则：一屏只有一个强调色；状态色只出现在圆点、文字与 20px 小标签上，禁止大面积色块。

### 字体

- 正文：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei"`
- 数据：`ui-monospace, "SF Mono", Consolas`，用于域名、URL、IP、ms、状态码、时间
- 层级：页面标题 20/500 · 区块标题 14/500 · 正文 13/400 · 辅助 12/400 · 表头 11.5/500 · 极小 10.5 mono
- 中文最小 12px，10.5px 仅用于纯数字/时间，不用于中文

### 间距与形状

- 8pt 网格：4 / 8 / 12 / 16 / 24 / 32
- 控件高 30px（小号 26px）；表格行 44px，紧凑模式 36px
- 圆角：控件 6px，面板 10px，抽屉/弹窗 12px
- 阴影只用于浮层（抽屉、弹窗、Toast）

## 3. 信息架构调整

```
监测   面板      概览：KPI → 站点表 → 报警/探针侧栏
       站点      全量列表：搜索 / 状态筛选 / 批量操作 / 详情抽屉   ← 新增独立页
       报警      未读优先 / 类型筛选 / 详情抽屉
调试   请求器
       接口测试 / 压力测试 / 渗透测试（待建，导航保留占位）
工具   在线工具  左侧工具导航 + 右侧工作区（不再一工具一弹窗）
       探针      节点在线状态与接入命令                        ← 原「监测器」更名
系统   设计规范  本页，仅设计稿阶段存在
```

改名理由：现在「监测器」页展示的是探针节点，而真正被监测的网站列表挤在「面板」里，两个概念容易混淆。拆成 **站点**（被监测对象）与 **探针**（执行监测的节点）后，导航语义唯一。

## 4. 页面改造对照

| 页面 | 现在 | 改版后 | 关键交互变化 |
|---|---|---|---|
| 面板 | 4 个大按钮 + 2 卡片 + 大表格 | 4 项 KPI + 站点表 + 报警/探针侧栏 | 行点击进详情；操作收敛；KPI 可一眼判断健康度 |
| 站点 | 无独立页，混在面板 | 独立列表 + 筛选 + 批量 | 多选后浮出批量条；行内只留「详情」+「···」 |
| 探针 | 表格 + "Monitor List Info" 占位文案 | 节点表 + 在线状态 + 接入命令 | 心跳时间、离线时长可见；接入步骤内联 |
| 报警 | 11 列表格 + 3 个按钮 | 筛选 + 未读圆点 + 详情抽屉 | 行点击看完整上下文；已读/删除在抽屉内 |
| 工具 | 8 张卡片，每张弹一个 Modal | 左导航 + 右工作区，结果内联 | 查询结果留在页面；历史 chips 可回看 |
| 请求器 | 三栏 + 大量 modal | 历史树 + 请求构建 + 响应三段式 | 方法/URL 常驻顶栏；响应状态码高亮 |
| 创建监测 | 3 步弹窗（下一步 ×2） | 单页分区表单 + 可选高级区 | 一屏填完；高级项折叠，默认不打扰 |

## 5. 交互设计清单

**已体现在原型里**
1. 侧栏分组（监测/调试/工具/系统），当前项高亮 + 左侧 2px 指示条。
2. 顶栏常驻：面包屑、全局搜索（`/` 聚焦）、探针在线数、未读报警、强调色切换、密度切换。
3. 表格行整行可点 → 右侧抽屉；`Esc` 关闭；遮罩点击关闭。
4. 行操作 = 「详情」+「···」；复制域名按钮 hover 才出现。
5. 站点多选 → 浮出批量条（已选数量 / 暂停 / 删除 / 取消）。
6. 工具页结果内联 + 最近查询 chips。
7. 创建监测：单页分区，高级项折叠展开。
8. 报警详情抽屉内给出"网络环境"判断（对照组与 Ping 正常 → 目标站点问题）。
9. 统一 Toast（右下、2.2s、深色）；统一空状态（图标 + 一句说明 + 主操作）。
10. 紧凑/舒适两种密度，适配小屏笔记本。

**建议后续迭代（需后端配合）**
11. 全局搜索真正跨站点/报警/工具检索（现在仅前端提示）。
12. 深链：`/sites?host=<hostID>` 直接打开详情抽屉，便于分享定位。
13. 批量暂停/删除接口；站点标签与分组。
14. 抽屉内直接编辑监测点/阈值（PATCH），不再跳设置页。
15. 图表时间范围切换（24h / 7d / 30d）与阈值线联动。

## 6. 实施映射（定版后按此改）

**纯前端，零后端改动**
- 新增 `master/static/css/theme.css`：本文第 2 节 token + 组件样式（可整体替换现有 `page.css` 的布局部分）。
- 重写 `views/public/__start__.html`（字体、meta、引入 theme.css）。
- 重写 `views/public/__header__.html`（顶栏）与 `__menu__.html`（侧栏）。
- 改造 `views/page/home.html`、`monitor.html`（→ 探针）、`alert.html`、`tool.html`、`requester.html`、`login.html`。
- 新增 `views/section/site_drawer.html`、`alert_drawer.html`；`add_host_modal.html` 改为单页分区。
- `static/js/public.js` 增加 `UI.drawer / UI.toast / UI.confirm / UI.skeleton`，Ajax 错误统一提示。
- 图标沿用 `routers/svg.go` 的 `SVG` FuncMap，补齐 8~10 个线性图标（search / plus / more / copy / edit / pause / trash / chevron / server / activity）。

**需要新增路由或接口**
- `/sites` 独立页：复用 `/api/website/list`，仅新增页面路由。
- 批量操作、全局搜索、深链参数：需新增 API 或查询参数，建议放到下一迭代。

**兼容注意**
- Go 模板定界符仍是 `{[ ]}`，与 Vue 的 `{{ }}` 不冲突，保持不动。
- Bootstrap 5 目前承担 Modal/Toast/栅格。策略：**保留 Bootstrap JS 与栅格，视觉全部由 theme.css 接管**；不引入构建工具，继续 CDN + 本地静态资源。
- 现有 `page.css` 里的 sidebar/navbar/box 样式需要清理，否则会与新组件互相覆盖。
- 表格滚动高度不要再用 `calc(100vh - 468px)` 这类魔法值，改为 flex 布局 + `min-height:0`。
